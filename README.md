# NextDNS Blocklists

Definitions for the ad and tracker blocklists available in [NextDNS](https://nextdns.io).

- **Suggest a list:** open an issue with the project page and direct source URL. We prioritize popular, actively maintained lists.
- **Report incorrect blocking:** contact the maintainer of the responsible list. For NextDNS Recommended, open an issue here with the affected domain and what breaks.
- **Report a broken source or integration issue:** open an issue here.
- **Get help with NextDNS:** visit the [Help Center](https://help.nextdns.io).
